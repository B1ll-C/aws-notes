# 01 · Cloud Fundamentals

## AWS Concepts & Services Covered

- Cloud computing models (IaaS, PaaS, SaaS) and deployment models
- AWS global infrastructure: Regions, Availability Zones, edge locations
- The AWS Management Console, account setup, and the AWS CLI
- The shared responsibility model
- Pricing, billing, the Free Tier, and budget alerts
