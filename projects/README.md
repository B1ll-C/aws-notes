# Projects

Hands-on builds that combine multiple AWS services: the place to document end-to-end projects from NextWork (or my own ideas).

## What Goes Here

- Projects that use **two or more** AWS services together (e.g. a web app on EC2 serving files from S3).
- Single-service exercises usually belong in that service's topic directory instead.

Use the same [`TEMPLATE.md`](../TEMPLATE.md). For projects, it's especially worth adding:

- An **architecture diagram** in the Description section.
- A list of **all AWS resources created**, plus a **Cleanup** step for deleting them.
